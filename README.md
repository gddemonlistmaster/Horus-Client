# Horus Client

A client-side Fabric visual dashboard and customizable HUD for Minecraft Java Edition **1.21.11**.

## Visuals

- A polished dark dashboard with violet/teal accents and a live HUD preview.
- Toggle the Aurora HUD, accent color, and profile indicator in-game.
- Open the dashboard with **Right Shift**, or use **Horus Visuals** from the pause menu.
- Client-only: it does not change server gameplay or require server installation.

## Build

Requirements: **JDK 21** and Gradle 8.14 or newer.

```sh
gradle build
```

The mod jar is created in `build/libs/`. Install Fabric Loader and Fabric API for Minecraft 1.21.11, then put the jar in that instance's `mods` folder.
